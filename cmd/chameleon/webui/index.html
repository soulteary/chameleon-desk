读取卡片存储与协议
先读取设备能力，再输入目标 UID 或选择 LF 协议。这里只读取，不写物理卡或自动保存到卡库；中断结果会标明不完整。密钥和密码不自动保存，读取后会清空输入。导出结果可能含卡片密钥。

 
Classic 分扇区密钥读取

  

  
  
实际读取以 JSON 中的 UID 和扇区列表为准；模板字段仅用于生成输入。扇区从 0 开始连续排列，每扇区至少提供一个六字节密钥。不会猜测或恢复未知密钥。

  

 

 
Type2 指定页读取

  

  
页范围限 0–255；实际容量由卡片决定。不自动判断容量，不做密码认证。每组读取前后核对 UID；协议可能连读相邻四页，结果只保留指定范围。
